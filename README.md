# Mycoscape

A NeoForge 1.21.11 Minecraft mod, forked from the legacy Mycoscape tech project, refocused entirely on environmental worldgen, a fungal forest biome, and a full decorative block palette built around mushrooms and rotwood.

## What it adds

**Fungal Forest biome**: a rare, eerie Overworld biome with a dark color palette, fungal ambience, and soul sand valley atmosphere.

**Rotwood wood set**: a full vanilla-parity wood set in a corrupted dark wood style.

**Mushroom blocks**: four species with grow stages (Blewit, Morel, Jack O'Lantern, Necroshroom) and giant mushroom cap blocks for each species.

**Terrain blocks**: Overgrown Grass, Mycoslate, Necroshroom Hyphae, Jack O'Lantern Vein.

**Mushroom food items**: Blewit, Morel, Jack O'Lantern Mushroom, and Necroshroom are all edible with custom status effects.
